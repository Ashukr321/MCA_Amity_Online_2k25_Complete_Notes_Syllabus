# Minor Project Documentation — AI-Powered Resume Screening & Candidate–Job Matching

This folder contains the Minor Project report package, written per the Amity University Online
*Minor Project / Seminar Evaluation: Guidelines* (see `MinorProject_guideline.pdf` and
`minor project guideline task_todo.pdf` in the repo root).

This is a **secondary-research report on the industry trend of AI in recruitment** — it is written as
an academic study, not as software/build documentation. It references **SkillMatch AI** only as a
brief illustrative example to make the discussion concrete; it does not list the project's API
endpoints, database collections, or implementation status, since that kind of build-status detail
belongs in engineering docs, not an academic secondary-research submission.

## Building the Word document yourself

Each file above starts with a hidden marker: `<div style="page-break-before: always;"></div>`. When
you copy each section into Word (or paste the whole thing into a Markdown‑to‑Word converter), put your
cursor at the start of each numbered heading and insert **Insert → Break → Page Break** (Ctrl+Enter in
Word) so every topic starts on its own page, matching how a formal report is normally laid out.

Formatting to apply once assembled:
- **Font:** Times New Roman, size 12, double-spaced
- **Margins:** 1 inch (2.5 cm) on all sides
- **Title page:** add your name, university, and date before Section 1
- **Length:** keep the combined body (excluding title page & references) between **2,000–3,500 words**
